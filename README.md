# Módulo 4 · Unidade 4 — Integrações Avançadas com Bancos de Dados e Ferramentas Externas

Página didática interativa de apoio aos alunos do **Curso de Formação em IA Generativa**.

## Sobre esta Unidade
Unidade de encerramento do módulo e do curso, conectando o raciocínio do modelo aos dados da organização e às ferramentas externas: protocolo **MCP** (*Model Context Protocol*), comunicação **A2A** (*Agent-to-Agent*), consultas sob demanda, cache e guardrails, níveis de integração com CRM/ERP, governança, ROI e métricas essenciais.

### Recursos da Aplicação
- **Simulador Visual Dinâmico**: Fluxo animado de integração segura via MCP + Guardrail + Banco de Dados.
- **Conteúdo Interativo**: Tópicos com explicações *Do Zero*, *Na Prática*, *Atenção / Risco* e *Ponto-chave*.
- **Quiz de Fixação**: 10 perguntas com feedback imediato e explicação.
- **Jogo da Memória**: Combinação de conceitos e definições da unidade.

## Stack Tecnológica
- **Next.js** (App Router com `output: "export"` para deploy estático)
- **Tailwind CSS**
- **Lucide React**

## Como executar localmente
```bash
npm install
npm run dev
```

## Publicação na Vercel
Importe o repositório no GitHub, selecione o diretório `MOD4/U4-WEB` como **Root Directory** e faça o deploy (sem necessidade de banco de dados ou variáveis de ambiente).
